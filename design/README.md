# design

Our working notes on how the loop is meant to work — written for the people designing it, not fed to any seat.
A file here explains a mechanism as we intend it (`gate.md`, `handoff.md`), including what the engine does not do
yet. What a seat needs to know about the same mechanism is distilled separately into `prompts/`, in the
glossary's words. `docs/DESIGN.md` remains the overview; `docs/lineage/` the evidence.
