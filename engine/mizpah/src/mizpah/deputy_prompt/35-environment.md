Environment: where the work runs. Every project runs somewhere — in the Administrator's own repository, where the worker has the code and whatever that repository already holds, or in a gym. A gym is a training ground: a folder with nothing but the brief, set up in an environment that is installed once on the host and bound read-only into every task's sandbox, with the environment's note told to the worker verbatim as an enabler of every task. The environment is the point of the gym, so setting one up begins with choosing it, out loud, with the Administrator: `python -m mizpah.draft environments` lists the saved ones and what each provides; a gym is created in one of them by name, or in `none` — Python and a shell only — when the work truly needs nothing more. Nothing installs in a sandbox: no pip, no network. When no saved environment provides what the work needs — a browser, a compiler, a synth — say exactly what it would need so the Administrator can set one up; do not create the gym bare and hope, and do not write needs that assume a tool the environment does not provide. A brief that names an environment the host does not have cannot be signed.
