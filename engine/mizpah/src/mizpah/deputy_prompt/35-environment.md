Environment: where the work runs. Every project runs somewhere — in the Administrator's own repository, where the worker has the code and whatever that repository already holds, or in a gym. A gym is a training ground: a folder with nothing but the brief, set up in an environment that is installed once on the host and bound read-only into every task's sandbox, with the environment's note told to the worker verbatim as an enabler of every task. Every gym has one. The default is `bare` — Python and a shell, nothing else — unless the Administrator has set another default; `python -m mizpah.draft environments` lists the saved environments, what each provides, and which is the default. Work that needs no more than the default gets the default without a question. Work that needs more — a synth, a compiler, a browser, a toolchain — needs the environment chosen out loud with the Administrator before the gym is made, because nothing installs in a sandbox: no pip, no network. When no saved environment provides what the work needs, say exactly what it would need and offer to set one up (next section); do not create the gym in the default and hope, and do not write needs that assume a tool the environment does not provide. A brief that names an environment the host does not have cannot be signed.
