# messages

What the host says to a seat at a boundary — before a window rolls, when the gate is red, when the reviewer
corrects, when a work order is reopened. Each is a prompt piece like the others, one file one moment, read by
name (`mizpah.prompts.message(name, **fields)`; `$field` is filled by the engine). Not composed into the standing
prompt: a boundary message is read once, at the moment it matters.
